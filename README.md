## `$ ./projects --featured`

### 01. NetCam --- Distributed Camera Intelligence

A camera-network intelligence platform designed to connect camera feeds
and help trace an object's movement across multiple locations.

-   Object detection with **YOLOv8** and multi-object tracking with
    **DeepSORT**.
-   ANPR integration for extracting and matching vehicle license plates.
-   Detection-event processing to organize observations into a
    chronological trajectory.
-   Backend APIs and map-based visualization of camera observations.

**Stack:** Python · FastAPI · React · YOLOv8 · DeepSORT · OpenCV

Repository: [NetCam](https://github.com/AvtaarKumarSingh/Netcam) ·
[Trained ANPR model](https://github.com/aviralb1311/anpr-car)

### 02. Subscription Management System

A subscription and billing platform built around the business lifecycle,
from product and pricing configuration to invoicing and payment
reconciliation.

-   Authentication and role-based access control.
-   Product catalog, pricing versions, and customer quotations.
-   Subscription lifecycle and invoice management.
-   Payment allocation, reconciliation, and credit-note workflows.
-   Dashboard metrics including MRR, ARR, and churn.

**Stack:** React · TypeScript · FastAPI · PostgreSQL · SQLAlchemy ·
Alembic

Repository: [Subscription Management
System](https://github.com/aviralb1311/Subscription-Management-System)

### 03. Local Career Assistant

A privacy-conscious desktop application concept for discovering job
opportunities and organizing career workflows, with local persistence.

-   Desktop architecture using Electron and React.
-   SQLite-based local data persistence.
-   Secure credential storage and a controlled preload API.
-   AI-assisted workflows designed around user control of applications
    and data.

**Stack:** Electron · React · TypeScript · Vite · SQLite

Repository: [Local Career
Assistant](https://github.com/aviralb1311/local-career-assistant)

### 04. Expense Tracker Backend

A backend project for managing expense records through API endpoints and
relational data models.

-   REST API development with Node.js and Express.
-   PostgreSQL data storage and Prisma ORM.
-   Schema design and database migration workflow.

**Stack:** Node.js · Express.js · Prisma · PostgreSQL

Repository: [Expense
Tracker](https://github.com/aviralb1311/expense-tracker)
